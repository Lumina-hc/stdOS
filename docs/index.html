StdOS

A lightweight 32-bit operating system with FAT16 filesystem, disk I/O, and shell.

View on GitHub Build Now

Features

32-bit Protected Mode

Runs in 32-bit protected mode with full memory protection.

FAT16 Filesystem

Full FAT16 support with directory and file operations.

Disk I/O

IDE PIO mode for direct disk read and write.

Shell

Built-in shell with common commands like ls, cat, mkdir.

Keyboard Driver

PS/2 keyboard input support.

Bootable Image

Generates bootable disk images ready for QEMU or real hardware.

Shell Commands

Command Description
helpShow help

aboutShow version
lsList directory
cat <file>Read file
cd <dir>Change directory
mkdir <dir>Create directory
rm <file>Delete file
write <file> <data>Write file
echo <text>Print text

Build

  1. Install dependencies: NASM i686-elf-gcc QEMU
  2. Clone the repository: git clone https://github.com/Lumina-hc/stdOS.git
  3. Enter the directory: cd stdOS
  4. Build: make.bat
  5. Run in QEMU: qemu-system-i386 -hda stdos.img
